# Location Fit: sources for result content

Every factual statement in `src/data/fitOrientation.ts` ("Why it fits", "What I'd want you to know", "If I were showing you the area...") is listed here with its source. Researched 2026-10-13. Re-check before relying on time-sensitive details.

The UI does not display citations; this file is the record.

| Statement used | Source |

| Lake Bella Vista, Silver Lake, Bostwick Lake are Rockford-area lakes | Amie (personal and professional experience); `src/data/lakes.ts` |

**Deliberately not stated:** which lakes are "all-sports," acreage, depth, public launches, no-wake rules. Search results for these came only from real-estate listings and conflicted (e.g. Bostwick Lake acreage and public access). The copy talks about *comparing* activity levels, launch arrangements and lake rules instead.
